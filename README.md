# AI Mind of Madness

Public fresh-start site, designed with editable HTML/CSS text, with six category pages. All items are previews while checkout and product testing are pending.

Original site's source and games remain preserved in GitHub branch `website-source` and its archive; they are not included in this branch's public pages.

The generated original artwork from the design conversation is not yet incorporated into hosting; current page uses replaceable background images. Product screenshots are illustrative examples, not finished tools.
